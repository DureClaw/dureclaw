보안 정책 안에서,
사내 컴퓨터를 하나의 팀으로

외부 접속 포트를 열지 않고 사내 Windows·현장 PC·서버에 일을 맡깁니다. 비밀키는 관리자 Mac 한 곳에만 둡니다.

회사·조직

이런 고민이 있다면

  • 원격 접속을 열기가 부담스럽다SSH·원격 데스크톱을 열려면 방화벽·계정·권한 협의가 필요합니다.
  • Windows가 섞이면 자동화가 멈춘다관리자 권한·UAC·인코딩 문제로 무인 작업이 중간에 막힙니다.
  • 현장 PC는 손댈 수 없다MES·ERP 화면만 있는 오래된 PC는 API가 없어 사람이 직접 입력합니다.

실측
MacWindows 11

포트를 열지 않고 사내 Windows에서 빌드까지

상황관리자 계정의 Windows 11 PC에 Python 프로그램을 exe로 빌드해 회수해야 했습니다.
SSH로는인증 시도 4번이 연달아 실패했고, 마지막엔 UAC 승인 창에 막혀 작업을 하나도 실행하지 못했습니다.
DureClaw로는추가 설정 없이 작업 5개(정보 수집→파일 생성→빌드→회수→화면 캡처)를 모두 성공했습니다.
0추가 설정
5/5작업 성공
14.3초전체 소요
7.35MB빌드된 exe

리포트의 정직한 한계: SSH가 불리했던 주된 이유는 'Windows·관리자 계정·무인 실행' 조합입니다. 키를 미리 심어 둔 Linux↔Mac 환경이라면 작업당 비용은 비슷합니다.
