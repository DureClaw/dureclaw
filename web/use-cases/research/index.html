실제 사례
브라우저 노드(webclaw)

대학 LMS에서 과제 12건을 받아 학생별로 정리

상황학습관리시스템에서 채점용 제출물 12건을 내려받아 정리해야 했습니다.
DureClaw로는로그인된 브라우저 노드가 실제 링크를 읽어 내려받고, 파일 크기와 폴더 구조까지 확인했습니다.

기록된 한계: 이 정도의 '브라우저 한 개' 작업만이라면 다른 브라우저 도구가 더 매끄러웠습니다. 이점은 그 뒤에 GPU 채점·성적표 작성 같은 다른 컴퓨터 작업을 이어 붙일 때 생깁니다.

출처 — 브라우저 에이전트 비교 문서

예시 시나리오
브라우저GPU 서버Windows

과제 수집 → GPU 표절 검사 → 성적표 작성

구상브라우저 노드가 제출물을 받고, GPU 서버가 표절·이상 탐지를 돌리고, Windows가 엑셀 성적표를 만듭니다.
포인트서로 다른 세 컴퓨터를 한 번의 지시로 잇는 흐름입니다. 아직 측정 수치는 없습니다.
