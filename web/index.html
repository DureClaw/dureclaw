DureClaw는 무엇인가요?

여러 대의 컴퓨터를 하나의 팀으로 묶어 주는 도구입니다. 역할은 셋뿐입니다.

  • 🧠두뇌 — Mac에서 쓰는 Claude Code. 무엇을 할지 생각하고 일을 나눕니다.
  • 🤲손 — 각 컴퓨터에 설치된 작은 에이전트. 받은 일을 실행하고 결과를 보고합니다.
  • 🚌버스 — Mac의 서버 앱. 두뇌와 손을 실시간으로 이어 줍니다.

Windows에서만 되는 엑셀 작업, GPU 서버의 학습, 라즈베리파이의 센서 — 기계마다 잘하는 일을 한 번의 지시로 동시에 돌립니다.

3단계면 팀 완성

STEP 01
Mac에 서버 앱 설치
DureClaw.dmg를 내려받아 실행. 메뉴 막대에 아이콘이 생기면 서버가 켜진 것입니다.
STEP 02
다른 컴퓨터 연결
Windows는 설치 프로그램, Linux·라즈베리파이는 한 줄 명령. 비밀번호·키를 나눠 줄 필요 없이 같은 사설망(Tailscale)이면 자동 승인됩니다.
STEP 03
Claude에게 말하기
Claude Code에서 /두레팀 또는 “윈도우에서 빌드하고 라즈베리파이로 테스트해줘”. 배분·실행·결과 취합은 알아서.

원격 접속(SSH)과 뭐가 다른가요?

SSH는 기계마다 접속 방법·인증·명령어가 다릅니다. 특히 Windows가 섞이는 순간 설정이 급격히 어려워집니다.

  • ✅들어오는 문을 열지 않는다 — 각 컴퓨터가 서버로 먼저 연결하므로 방화벽·포트 설정이 필요 없습니다.
  • ✅OS 차이를 감춘다 — Windows·Linux·Mac에 같은 방식으로 일을 시키고 같은 형식으로 결과를 받습니다.
  • ✅여러 대를 한 번에 — 한 줄 지시로 여러 기계가 동시에 움직입니다.

키 없이도 안전하게

마스터 비밀키는 Mac 한 곳에만 있습니다. 다른 컴퓨터에는 복사하지 않습니다.

  • 🎫개인 출입증 — 새 컴퓨터가 가입을 요청하면 서버가 그 컴퓨터 전용 토큰을 발급합니다. 필요하면 하나씩 회수할 수 있습니다.
  • 🔒사설망 자동 승인 — 같은 Tailscale 망이면 클릭 없이 승인, 밖에서 오면 운영자가 확인합니다.
  • 🧭지시는 한 곳에서만 — 팀원 컴퓨터는 일을 받고 보고만 할 수 있고, 다른 컴퓨터에 지시할 수 없습니다.

🖥️
맥 + 서버/워크스테이션 보유 개발자
메인 Mac + GPU 서버 or Linux 박스
기존: Claude Code는 맥에서만. 서버는 별도 SSH로 수동 작업.
DureClaw: Mac Claude가 지시하면 서버가 동시에 빌드·테스트·학습 실행.
🤖
집·회사 멀티 셋업 개발자
회사 Mac + 집 워크스테이션 (Tailscale로 연결)
기존: 한 곳에서만 작업 가능. 다른 머신은 놀고 있음.
DureClaw: 어디서든 Claude에게 말하면 두 머신이 동시에 태스크 수행.
👥
소규모 팀·스터디그룹
팀원 각자의 머신에 AI 에이전트 설치
기존: AI 도구를 각자 따로. 결과 공유가 느리고 번거롭다.
DureClaw: 팀장 Claude가 태스크 배분 → 모든 머신이 협력해서 결과 통합.
