## 1. 트랙 선택 + 근거

### 추천: **GTM 트랙** (확정 추천)

DureClaw는 이미 **작동하는 제품**이다. 멀티머신 라이브 데모, Pi 신호등 실증, RSI eval 루프, 결정론적 결정화(110,000배 실측)까지 기술적으로 "막힌 문제"가 아니라 "퍼뜨리는 문제"가 핵심 단계다. 행사 멘토 라인업도 GTM 쪽에 결정권자가 몰려 있다 — Guillaume Princen(International DNBs & Startups), Yeop Lee(APAC Startup Partnerships), Taeyang Lee(BASS CEO). 이들은 DureClaw가 가장 필요로 하는 **분배 채널과 파트너십 자원**을 직접 쥐고 있다.

GTM 트랙에서 다듬어야 할 진짜 질문은 명확하다:
- 오픈코어 분산 에이전트 인프라의 **수익화 경계** (무엇을 오픈, 무엇을 유료)
- **누구에게 먼저** 파나 — 제조(MES/PdM), 로봇/IoT, 개발자 함대 중 wedge 시장
- Anthropic 생태계를 **GTM 채널로** 활용하는 법 (Claude Code 플러그인 마켓, 스타트업 프로그램, 공동 레퍼런스)

## 2. 신청서 핵심: "90분 안에 풀고 싶은 문제"

> 신청 심사는 **문제의 구체성**으로 멘토·트랙을 배정한다. 추상적인 "성장 전략 조언"은 탈락 신호. 측정 가능한 의사결정 한 개를 못 박아야 한다.

### 후보 A — 추천 ✅ (수익화 경계 + Anthropic 채널)

> "DureClaw는 Claude를 분산 엣지 디바이스(라즈베리파이 $5부터 Mac/Windows/Linux까지)의 공유 브레인으로 쓰는 오픈코어 에이전트 함대입니다. 마스터 노드 한 곳에만 Claude 인증을 두고, 키 없는 엣지가 판단만 위임받아 한 번 배운 정책을 로컬 스킬로 동결해 이후 결정론적으로 µs 단위 실행합니다(실측 11만 배 가속). 제조 예지보전(PdM) 라이브 데모까지 작동합니다. 90분 안에 풀고 싶은 문제: **오픈코어 경계를 어디에 그어야 채택을 막지 않으면서 수익화하고, Anthropic 생태계(Claude Code 플러그인·스타트업 프로그램·MCP)를 우리 GTM 채널로 어떻게 정합시킬지** — 첫 유료 wedge 시장(제조 PdM vs 개발자 함대) 선택과 그에 맞는 패키징·가격 가설을 함께 검증하고 싶습니다."

- **왜 이게 통과하나**: 제품이 작동함을 증명(신뢰), 의사결정 1개로 좁힘(수익화 경계 + wedge), Anthropic을 채널로 명시(파트너십 유인). Princen/Yeop Lee/Taeyang Lee가 모두 답할 수 있는 질문.

### 후보 B — Anthropic 직접 파트너십 앵글

> "DureClaw가 Anthropic의 첫 **공식 분산 엣지 레퍼런스 케이스**가 되려면 어떤 조건을 충족해야 하나? 공동 블로그·데모, 스타트업 크레딧, Claude Code 플러그인 마켓 피처링까지 — 90분 안에 협력 패키지의 현실적 범위와 다음 액션을 합의하고 싶다."

- 강점: 파트너십에 직진. 약점: 멘토 입장에서 "우리가 무엇을 받나"가 약하면 일방적 요청으로 보일 위험. 후보 A에 흡수해 쓰는 게 안전.

### 후보 C — APAC GTM 특화

> "한국발 오픈코어 인프라가 APAC 제조 현장(MES/PdM)에서 Claude 채택을 견인하는 wedge가 될 수 있나? 90분 안에 APAC 진입 시퀀스와 첫 등대 고객 프로파일을 정의하고 싶다."

- 강점: Yeop Lee(APAC) / Taeyang Lee(Toss) 직격. 약점: 시장이 좁아 보일 수 있음. 후보 A의 wedge 논의에 지역 레이어로 덧붙이는 게 좋다.

**최종 제출: 후보 A.** B의 파트너십 요청과 C의 APAC 앵글을 본문 한 줄씩으로 흡수. 멘토 배정 시 Princen + Yeop Lee 조합을 유도.

## 4. 3분 데모 시나리오 (5:00, 트랙별 데모)

> 핵심 원칙: **말이 아니라 물리 세계가 움직이는 걸 보여준다.** $5짜리 Pi가 Claude의 판단으로 신호등을 켜고, 다른 머신이 이상을 음성 경보하는 장면이 메시지 전부다.

### 대본 (총 3분)

**[0:00–0:20] 훅 — 한 문장 + 화면**
"이 방 안의 노트북, 그리고 제 가방 속 5달러짜리 라즈베리파이가 지금 하나의 AI 팀입니다. Claude는 한 곳에만 있고, 나머지는 손만 빌려줍니다." → 한 화면 대시보드에 4개 노드(Pi·Mac·Linux·Windows) presence 점등.

**[0:20–1:10] 라이브 루프 1바퀴**
- Pi의 초음파센서 앞에 손을 가져감 → 거리값이 버스로 스트리밍되어 대시보드에 실시간 표시.
- 마스터 Claude/pi가 정책 판단(예: "근접 → 경고") → Pi의 3색 LED가 빨강으로 점등. **"여기서 Claude가 판단했습니다."**

**[1:10–2:00] 결정론적 결정화 — 차별점의 핵심**
- "방금 판단을 엣지가 로컬 스킬로 **동결**했습니다. 이제 같은 상황에서 Claude를 다시 부르지 않습니다." → 손을 다시 가져감 → LED가 **즉시**(µs) 반응. 대시보드에 latency 비교: 첫 추론 vs 동결 후(~11만 배 가속) 숫자를 띄움.
- 메시지: "한 번 배우고, 이후 결정론적으로. 비용·지연·신뢰성을 동시에 잡습니다."

**[2:00–2:40] PdM 레이어 — 산업 임팩트**
- 스트리밍된 측정값을 Linux가 수집 → IsolationForest 이상탐지 → Windows가 실시간 추론·**음성 경보** 발생(이상 패턴 주입). "이게 제조 예지보전입니다. Pi=설비 모니터, LED=Andon, 이상탐지=PdM."

**[2:40–3:00] 클로징 + ask**
"폐쇄망·Tailscale에서, 원라이너 설치로, $5 디바이스까지. DureClaw는 Claude를 현장으로 데려갑니다. Anthropic의 첫 분산 엣지 레퍼런스를 함께 만들고 싶습니다."

### 데모 실패 대비 백업 (3중)

1. **네트워크 끊김** → 모든 노드를 Tailscale 한 서브넷에 사전 고정 + **로컬 핫스팟 폴백**. 행사 와이파이 의존 금지.
2. **하드웨어 불능(Pi/센서)** → 동일 루프의 **사전 녹화 영상(90초)** 준비. "라이브가 이상적이지만, 어제 찍은 실측입니다"로 무손실 전환.
3. **마스터 인증/LLM 호출 실패** → 동결된 로컬 스킬은 LLM 없이도 동작하므로, **결정화 이후 단계만으로** 데모 가능(이게 오히려 차별점을 강화). 첫 추론 부분만 녹화로 메움.
4. **시간 초과 리스크** → 1:10–2:00(결정화)이 메인, PdM(2:00–2:40)은 시간 부족 시 한 문장 + 스크린샷으로 압축.

1. **공동 레퍼런스 케이스** — "Anthropic Customer Story / Built with Claude"에 DureClaw PdM 사례 등재. 가장 낮은 마찰, 가장 빠른 win.

3. **Claude Code 플러그인 마켓 피처링** — DureClaw는 이미 Claude Code 네이티브(스킬·에이전트 정의). 마켓 등재·추천이 곧 분배.
4. **공동 블로그/데모 콘텐츠** — "Claude on a $5 device" 앵글의 공동 기술 블로그. 시각적 데모가 강점.
5. **Agent SDK / MCP 공동 검증** — 기술 신뢰를 위해 Anthropic 엔지니어와 통합 리뷰(네트워킹에서 Katelyn에게).

> **상호성 프레이밍**: 모든 요청을 "우리가 Anthropic 생태계 확장에 기여 → 그 증거를 함께 마케팅" 구조로. 일방적 크레딧 요청으로 보이지 않게.

## 7. 포지셔닝 메시지 / 엘리베이터 피치

### 30초 버전
"DureClaw는 Claude를 분산 디바이스 함대의 **공유 브레인**으로 쓰는 오픈코어 에이전트 인프라입니다. 5달러짜리 라즈베리파이부터 Mac·Windows까지 하나의 AI 팀으로 묶고, 인증은 마스터 한 곳에만 둡니다. 엣지는 Claude의 판단을 **한 번만** 받아 로컬 스킬로 동결하고, 이후엔 LLM 없이 µs 단위로 결정론적으로 실행합니다 — 실측 11만 배 빠르게. **Local hands, remote brain.** 제조 예지보전이 지금 라이브로 돕니다."

### 2분 버전
"AI 에이전트를 현장에 깔려면 두 가지가 막힙니다. 디바이스마다 LLM 키를 뿌리는 건 비용·보안·관리 악몽이고, 모든 판단을 매번 LLM에 묻는 건 느리고 비쌉니다.

DureClaw는 둘 다 풉니다. 마스터 노드 **한 곳에만** Claude 인증을 두고, 키 없는 엣지 노드들은 센서·셸·GPIO 같은 현장 작업만 로컬에서 하고 **판단만 마스터로 위임**합니다 — brain-node delegation. Phoenix 상태서버 + Bun 데몬 + WebSocket 버스로 폐쇄망·Tailscale에서 작동하고, $5 armv6 라즈베리파이까지 진짜로 내려갑니다.

핵심 차별점은 **결정론적 결정화**입니다. 마스터가 비결정적으로 한 번 내린 정책을 엣지가 로컬 스킬로 동결하면, 이후 같은 상황은 재추론 없이 µs 단위로 결정론 실행됩니다 — 실측 11만 배 가속. 한 번 배우고, 이후 결정론적으로.

그리고 이건 데모가 아니라 작동합니다. 5달러 라즈베리파이에 초음파센서와 신호등 LED를 붙여, 현장 거리측정 → 마스터 Claude 판단 → 엣지 결정론 점등까지 라이브로 돕니다. 측정값은 버스로 스트리밍돼 Linux가 이상탐지 모델을 학습하고 Windows가 실시간 음성경보를 냅니다. 그대로 제조 예지보전(PdM) 노드입니다.

Anthropic에게 DureClaw는 Claude를 데이터센터 밖 물리 현장으로 넓히는 첫 분산 엣지 레퍼런스가 될 수 있습니다. 함께 만들고 싶습니다."
